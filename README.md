# Oasis Padel Academy

Corporate single-page website for Oasis Padel Academy — a premium padel
club and wellness destination in Da Nang, Vietnam. Bilingual (EN / VI).

## Stack

- React 18 + Vite 5
- Tailwind CSS 3
- Framer Motion 11 (animation)
- Lenis (smooth scroll)
- react-i18next (bilingual EN / VI)
- lucide-react (icons)

## Local development

```bash
git clone https://github.com/julinhio/oasis-padel.git
cd oasis-padel
npm install
npm run dev      # start the dev server
npm run build    # production build to /dist
npm run preview  # preview the production build
npm run lint     # run ESLint
```

## Deployment

Hosted on Vercel. Every push to `main` auto-deploys to production;
all other branches get preview deployments.
